Put your own legally obtained Halo: Combat Evolved Xbox .map files in this folder.

This repository does not include those files. Do not commit them.

Preferred names: ui.map and the campaign maps (a10.map, a30.map, a50.map, b30.map, b40.map, c10.map, c20.map, c40.map, d20.map, d40.map).

Loose .map files are the layout this DOL can read. An optional game.iso next to the app (sd:/apps/halo-ce/game.iso) is used only when no loose map was identified, and only when the image is under 2 GiB. This toolchain's fseek cannot pass 2 GiB.
